# html2figma logo exploration

The selected mark is **Two Path**: its continuous numeral 2 connects an orange source node to a blue output node. It names the conversion step in `html2figma` without borrowing Figma's icon geometry. The transparent mark is available as [SVG](logo.svg) and [1024 px PNG](logo.png).

[Open the interactive comparison](logo-concepts/index.html) to inspect all six directions at large, 32 px, and 16 px sizes, switch preview backgrounds, and download each SVG or PNG.

| Direction | Visual idea |
| --- | --- |
| Frame Shift | Source and destination frames overlap into a new editable region. |
| H Grid | Seven modular pixels form the H in HTML. |
| Two Path | The numeral 2 links a source point to a destination node. |
| Bracket Canvas | An HTML bracket flows into a selected canvas frame. |
| Materialize | Source pixels consolidate into one editable object. |
| Node Relay | DOM nodes converge into one output layer. |

The colors come from [Figma's Brand Book](https://static.figma.com/uploads/6645755656177435f83e10b48d9947645b55a033): red `#FF3737`, orange `#FF7237`, violet `#874FFF`, blue `#00B6FF`, and green `#24CB71`. The symbols themselves are original html2figma concepts.
