# html2figma logo

The mark's continuous numeral 2 connects an orange source node to a blue output node. It names the conversion step in `html2figma` without borrowing Figma's icon geometry. The transparent mark is available as [SVG](logo.svg) and [1024 px PNG](logo.png).

The colors come from [Figma's Brand Book](https://static.figma.com/uploads/6645755656177435f83e10b48d9947645b55a033): red `#FF3737`, orange `#FF7237`, violet `#874FFF`, blue `#00B6FF`, and green `#24CB71`. The mark itself is an original html2figma design.
