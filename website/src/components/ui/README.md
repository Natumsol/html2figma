# shadcn/ui components

Generated from the official shadcn/ui registry with `shadcn@4.21.4 add button card badge native-select tabs sheet navigation-menu accordion alert textarea --yes`.

Registry configuration and aliases live in `website/components.json`. Components import the local `cn` helper. Site composition lives in `../site/`; the six conversion examples use these primitives too. The theme is customized in `src/styles/shadcn.css`. Motion uses the site's easing and layer variables; Accordion avoids height animation.

Upstream: https://ui.shadcn.com/docs/installation/astro
